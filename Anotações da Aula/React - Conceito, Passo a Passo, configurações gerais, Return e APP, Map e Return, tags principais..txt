
1. React:

React é uma biblioteca de JavaScript usada para criar telas de sites e aplicativos.

Em vez de escrever códigos gigantes para cada página, o React funciona como um jogo de Lego: você divide a tela em blocos menores e reutilizáveis chamados Componentes (como um botão, uma barra de navegação ou um cartão de perfil).

O resumo do seu sucesso se deve a duas coisas:

Reutilização: Você cria um componente uma vez e o usa em vários lugares, mudando apenas os dados (como fez com a lista de funcionários).

Velocidade: Quando algo muda na tela (um clique, um novo texto), o React atualiza apenas aquele pedacinho específico, sem precisar recarregar a página inteira.

4. Return e App:

Quando o React chama a função App(), ele está perguntando: "O que eu devo desenhar na tela para o usuário?"

O return do App junta tudo isso (Header, título e a lista de cartões) e entrega a página inteira para o navegador renderizar.

5. Map e return:
O .map() passa de funcionário(objeto) em funcionário(objeto) na sua lista. A cada passada, o return cria um componente <CartaoPerfil/> preenchido com os dados daquele funcionário específico e o joga dentro da div "grade.
