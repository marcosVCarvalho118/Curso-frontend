3. For/While

"for"= é a repetição controlada (também chamada de laço ou loop).

Em vez de você escrever a mesma linha de código várias vezes, você usa o for para dizer ao computador: "Execute este bloco de código X vezes" ou "Execute este código para cada item desta lista

"while" = (que significa "enquanto") é uma das estruturas de controle fundamentais na programação. Sua função principal é repetir um bloco de código enquanto uma condição específica for verdadeira.

Diferente do "for", que geralmente é usado quando sabemos exatamente quantas vezes queremos repetir algo, o while é ideal para situações onde não sabemos de antemão quantas repetições serão necessárias.
