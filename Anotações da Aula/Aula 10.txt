Variável:
Cost .... - É o valor/número que não sofrerá alteração no Java script

let "variável" - Está declarando uma variável na java script. 
- let permite que você declare variáveis (dentro do par de chaves ()) limitando seu escopo no bloco, instrução, ou em uma expressão na qual ela é usada. Isso é inverso da keyword "var", que define uma variável globalmente ou no escopo inteiro de uma função, independentemente do escopo de bloco.
- Obs: A variável não pode ter espaço e a 2° palavra tem que ser iniciada por letra maiúscula.

${variável} é a forma de resgatar uma variável no let para o console JavaScript

If ... Else:
If é um valor de variável e o else é o valor contrario caso a variável do If seja falsa.


Configuração de Texto:

"" somente para texto
'' - Texto que contem variável de JavaScript. 
"=" está retomando o valor indicado
"+" para texto concatena ou para números soma
"\n": é usado no RegExp para corresponder a quebras de linha em textos

Comparação:

"==" é o igual(comparando) ignorando o tipo da informação (número, texto, etc.)
"===" é o igual(comparando) exatamente
"!" - é o valor contrario da sentença.
"<=": O operador  é o operador de comparação "menor ou igual a". Ele retorna verdadeiro se o valor da esquerda for menor ou igual ao valor da direita; caso contrário, retorna falso.

Conta/Números em JavaScript:

"-=" em JavaScript é o operador de atribuição de subtração. Ele subtrai o valor da direita da variável à esquerda e atualiza a variável com o resultado

"To fixed(n°)" - Ele têm a função de indicar número de dígitos que aparecem depois do ponto decimal.
