Estrutura de uma function em react:
uma HoF é uma função que recebe outra função como argumento ou que retorna uma função.

Você, inclusive, acabou de usar HoFs nos códigos anteriores que me mandou! O JavaScript usa esse conceito o tempo todo, especialmente quando lidamos com arrays.

Onde você usou HoFs no seu código?
No seu componente React, você utilizou duas das HoFs mais famosas do JavaScript: .filter() e .map().

.filter() é uma HoF: Ela recebe uma função como argumento para decidir quais itens do array devem ser mantidos.

.map() é uma HoF: Ela também recebe uma função como argumento para transformar cada item do array em algo novo (no seu caso, transformou os dados brutos da API em objetos formatados e depois em elementos JSX).
